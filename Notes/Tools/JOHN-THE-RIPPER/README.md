It is a offline cracker. It takes password hashes and match them locally. It targets 470+ hash/cipher formats:  LM/NTLM, SHA-1/256/512, MD5, bcrypt, WPA/W[a2, ZIP, KeePass, SSH keys, BItLocker,etc. It's attacks are single crack, wordlist, incremental, mask, rules(word mangling).  It works on CPU/GPU-bond; much faster since no network latency. It works on Unix, macOS, Windows, DOs, BeOS, OpenVms. It is licensed by GPL.
Use John the Ripper when you already have a hash(from /etc/shadow, a SAM dump, a captured WPA handshake, a ZIP file, etc.) and want to recover the plaintext locally(eg. john ---wordlist=rockyou.txt hash.txt).
